# Background audio

Drop a single royalty-free audio file in this folder (e.g. `background.mp3`) to have
it muxed into the daily video by `scripts/build-video.js`.

If this folder is empty, the pipeline produces a silent video by default — that's
intentional, since no license-cleared track can be bundled automatically.

Good free sources:
- YouTube Audio Library (studio.youtube.com -> Audio Library) — filter by "no attribution required"
- Pixabay Music (pixabay.com/music) — free license
- Instagram/Meta Sound Collection (business.facebook.com/sound-collection)

Keep the track at least as long as the video (currently ~15s) and prefer a calm,
minimal instrumental that fits the black/white/gray premium finance aesthetic.
